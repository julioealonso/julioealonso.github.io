Política de privacidad de contextOS

Última actualización: 20 de noviembre de 2026

contextOS es una aplicación de escritorio de uso personal que se ejecuta sólo en el equipo de su usuario. Esta política explica qué datos de Google usa y cómo.

Datos a los que accede

Con el permiso https://www.googleapis.com/auth/gmail.metadata, contextOS consulta únicamente el número de conversaciones sin leer de las etiquetas de Gmail que el usuario configura. No lee el contenido de los mensajes, los remitentes, los destinatarios ni los asuntos, y no envía, modifica ni borra correo.

Cómo se usan

El número de conversaciones sin leer se muestra en un widget del escritorio. No se usa para ningún otro fin, no se usa para publicidad ni para entrenar modelos de inteligencia artificial, y no se vende.

Dónde se guardan y con quién se comparten

Las credenciales de autorización se guardan en las variables de usuario de Windows del propio equipo. Los recuentos sólo existen en la memoria del programa mientras está abierto, con una caché de unos minutos. Nada de esto se envía a servidores del autor ni a terceros: la única comunicación es entre el equipo del usuario y las API de Google.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. También se puede borrar las variables CONTEXTOS_GMAIL_* de las variables de usuario de Windows.

Uso limitado

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
